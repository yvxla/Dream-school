# MY DREAM SCHOOL ♡

韓国高校生活をテーマにしたスマホ向けWebアプリです。

## 使い方
- `index.html` をブラウザで開くか、GitHub Pagesなどの静的ホスティングにアップロードしてください。
- 同じブラウザ内の `localStorage` に保存され、再読み込み後も復元します。
- 学校設定からJSONバックアップを書き出し・読み込みできます。

## 機能
- 1日の予定と完了チェック、気分、放課後の選択
- 友達・学校イベントの選択式ストーリーとログ
- 理想の部屋、家具、家賃・貯金目標
- 日記・写真アルバム
- 韓国語単語帳・勉強記録
- 貯金・収入・支出の記録
- 学校プロフィール、進学準備チェックリスト、メモ
- JSONバックアップ

## 注意
学校プロフィールは自由に作る理想設定です。実在する学校の入学条件・費用・制度を表すものではありません。進学情報は学校公式サイトや公的機関の最新情報で確認してください。localStorageは端末変更やブラウザデータ削除で消えることがあるため、定期的にバックアップしてください。
